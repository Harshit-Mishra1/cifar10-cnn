# CIFAR-10 Image Classification Using CNN

A beginner-friendly image-classification project built with **PyTorch** and **torchvision**. The CNN learns to classify 32×32 colour images into the 10 CIFAR-10 categories.

## Features

- Downloads CIFAR-10 automatically through `torchvision`
- Normalizes RGB image tensors
- CNN with three convolutional blocks (32, 64, and 128 channels)
- Trains with Cross-Entropy Loss and the Adam optimizer
- Evaluates accuracy on the official test set
- Saves the trained weights and evaluation metrics under `artifacts/`

## Setup

Python 3.10–3.12 is recommended for a straightforward PyTorch installation. Install a PyTorch build compatible with your operating system and hardware from the [official PyTorch installation selector](https://pytorch.org/get-started/locally/).

Create and activate a virtual environment.

### Windows Git Bash

The Windows Python launcher works even when Git Bash does not recognize the
`python` command. Python 3.10–3.12 is recommended for PyTorch; install Python
3.12 if it is not listed by `py -0p`, then run:

```bash
py -3.12 -m venv .venv
source .venv/Scripts/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Once the virtual environment is active, `python` refers to the environment's
interpreter. To run the project later, activate the environment first and use
`python train.py`.

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run training

From the project directory:

```bash
python train.py
```

The first run downloads CIFAR-10 automatically, so an internet connection and several hundred megabytes of free disk space are needed. Training time depends on your CPU/GPU.

At the end, the script prints test accuracy and writes:

- `artifacts/cifar10_cnn.pth` — trained model weights
- `artifacts/metrics.json` — epoch count and measured test accuracy

These generated files are excluded from Git by `.gitignore`. Run the script yourself and update this README with the actual test accuracy from your run; results can vary by hardware, software versions, and training conditions.

## Model overview

1. Input: 3-channel, 32×32 CIFAR-10 image
2. Three convolution + ReLU + max-pooling blocks
3. Flattened features passed through a 256-unit fully connected layer
4. Output: 10 class logits

## Dataset

CIFAR-10 contains 60,000 32×32 colour images across 10 classes: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, and truck. The official split contains 50,000 training images and 10,000 test images.

## Limitations and possible improvements

- This is a compact baseline CNN; accuracy can be improved with data augmentation, learning-rate scheduling, dropout, batch normalization, or a deeper architecture.
- The script reports overall test accuracy; per-class precision/recall and a confusion matrix would provide a more detailed evaluation.
